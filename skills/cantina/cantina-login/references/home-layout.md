# Cantina home layout

Verified 2026-10-19. The web app is labeled beta, so expect drift.

- Left nav: Home, Characters, Videos, Shows, Images, Rooms, Chats, Discover,
  Create Video.
- Chats panel lists conversations by bot name + latest message snippet.
- Right rail: ROOMS (e.g. The Bot Place, the user's Welcome Room) and
  FRIENDS with online / verified indicators.
- Logged-in identity appears in the bottom-left account menu and the top
  account button (name + @handle).
